# 🎬 Estrenos Arg

Aplicación web desarrollada con **React** que permite visualizar estrenos de películas en Argentina de forma simple, rápida y visual.

---

## 🚀 Demo

👉 *(Agregá acá el link cuando lo deployes — Vercel / Netlify)*

---

## 🧠 Descripción

**Estrenos Arg** es una aplicación frontend que consume datos de películas para mostrar los últimos estrenos disponibles.

---

## 🎯 Objetivo del proyecto

- Mejorar habilidades en **React**
- Practicar consumo de **APIs REST**
- Trabajar con **componentes reutilizables**
- Implementar **diseño responsive**

---

## ✨ Funcionalidades

- 📺 Visualización de estrenos de películas
- 🔍 Navegación
- 📱 Responsive

---

## 🛠️ Tecnologías utilizadas

- React
- JavaScript
- CSS
